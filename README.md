# OmniBoard Digital Playground 🎲

A free, serverless, peer-to-peer web-based board game hub hosted directly via **GitHub Pages**.

## 🌟 Highlights
- **100% Free**: No backend servers to run or pay for, zero subscriptions, zero credit card requirements.
- **Serverless WebRTC (P2P)**: Multiplayer connections run directly browser-to-browser via PeerJS data channels.
- **Modern Responsive Design**: Glassmorphism dark UI tailored for desktop, tablet, and mobile devices.
- **Automated Deployment**: Automatically deployed to GitHub Pages with GitHub Actions on push to `main`.

## 🎮 Included Games
1. **Connect 4 World** (`/connect4world/`):
   - A strategic rail & trade route claiming game inspired by Ticket to Ride mechanics.
   - 2-player competitive map featuring major world hubs (London, Paris, Berlin, Rome, Cairo, Moscow, Dubai, Tokyo).
   - Local Pass & Play and Instant Online P2P room sharing.
2. **Splendor Anime Edition** (Ready for import):
   - Slot prepared for AniList anime character card merchant game.
